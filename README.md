# Actively Backend

Backend API for **Actively**, an application for tracking and managing physical activities.

The API handles user authentication, activity data, statistics and route-related features, including map generation and geospatial data processing.

## Tech Stack

* **C# / ASP.NET Core Web API**
* **Entity Framework Core**
* **Microsoft SQL Server**
* **JWT Authentication**
* **Azure Key Vault**
* **Mapbox API**
* **Swagger / OpenAPI**
* **Dependency Injection**
* **xUnit**
* **FakeItEasy**
* **Microsoft Azure SQL Database**
* **Microsoft Azure Blob Storage**
